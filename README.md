# 송영찬 | Network & Security Engineer Portfolio

> 기업 네트워크를 직접 구성하고 동작을 검증하며 성장하는 엔지니어의 포트폴리오

- **공개 웹사이트:** https://aleph-songyc-01.vercel.app/
- **소개 및 경력:** `index.html`
- **프로젝트 상세:** `projects.html`
- **GitHub:** https://github.com/ychanis

## 소개

기계 설비 설치·유지보수 경험을 바탕으로 네트워크 및 보안 솔루션 엔지니어로 전향 중입니다. 단순한 기술 목록 대신 설계 근거, 실제 구현과 검증 여부를 구분하여 정리했습니다.

## 페이지 구성

### 1. 소개 · 경력

- 기술 지향점과 문제 해결 방식
- GNS3, Cisco IOS, Linux 등 사용 경험
- 이전 현장 경력과 네트워크 분야로의 전환 배경
- 대표 프로젝트 및 연락처

### 2. 포트폴리오

| 프로젝트 | 상태 | 주요 내용 |
|---|---|---|
| 글로벌 게임회사 네트워크 | 구축 및 일부 검증 | HQ/DEV/IDC/JP, 3-Tier, VLAN, DHCP, Routing |
| 일본 물류센터 네트워크 및 WMS | 진행 중 | LC 3-Tier, HSRP, 데이터센터 서비스 분리, API 계획 |
| 중소기업 보안 인프라 개인 프로젝트 | 계획 | FW/VPN/IDS/IPS/WAF/DMZ |

**상태 표시는 실제 진행 기록을 기준으로 합니다.** 포트폴리오에 검증 자료가 아직 첨부되지 않은 내용은 별도 증빙 예정으로 표기했습니다.

## 기술 구성

외부 프레임워크 없이 순수 HTML / CSS / JavaScript를 사용한 정적 사이트입니다.

```text
ALEPH_01/
├── index.html       # 소개 및 경력
├── projects.html    # 포트폴리오 전용 페이지
├── style.css        # 반응형 공통 스타일
├── script.js        # 모바일 탐색 메뉴
└── README.md
```

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

## 공개 및 보안 기준

- 개인 연락 수단은 공개용으로 선택한 이메일만 사용합니다.
- 자격증 취득 여부나 서비스 완성도를 과장하지 않습니다.
- 네트워크 도식은 연결 포트의 실제 물리도를 복제한 것이 아니라 설명용 개념도임을 명시합니다.
- 암호, 토큰, 실제 운영망 IP, 민감한 내부 자료는 공개하지 않습니다.
- 사진 및 실습 캡처는 사용자가 제공한 공개 가능한 자료만 적용합니다.

## 업데이트 계획

실제 인물 사진과 구축 캡처, 장비 설정 결과, 테스트 로그 및 토폴로지 원본을 정리해 추가할 예정입니다. 증빙을 추가한 항목부터 검증 상태를 명확하게 갱신합니다.
