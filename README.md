# ALEPH_01 — 나를 소개하는 한 페이지

정보보안 분야를 공부하면서 현재 학습하고 있는 내용과 실습 경험을 한 화면에 정리한 자기소개 페이지입니다.

단순한 이력이나 자기소개를 나열하기보다, 제가 어떤 방식으로 공부하고 문제를 해결하는지를 **상황 · 행동 · 결과**를 중심으로 보여주는 것을 목표로 제작했습니다.

## 🔗 배포 주소

**Website**  
https://aleph-songyc-01.vercel.app/

## 🛠 사용 기술

- HTML
- CSS
- JavaScript
- Git / GitHub
- Vercel

## 📌 주요 구성

### 1. Introduction
정보보안을 공부하고 있는 현재의 모습과 이 페이지를 만든 목적을 소개합니다.

### 2. Activity
현재 학습하고 있는 내용을 정리했습니다.

- 정보보안 기초
- Linux 명령어 및 서버 실습
- 네트워크 · DNS · NAT 구성
- 네트워크 문제 원인 확인 및 해결

### 3. Evidence
학습 내용을 단순히 나열하지 않고 실제 실습 과정에서 확인한 결과를 근거로 정리했습니다.

- 네트워크 통신 문제 해결
- Linux 명령어 실습
- DNS 동작 흐름 확인

### 4. Strengths & Experience
각 경험을 **상황 → 행동 → 결과** 순서로 작성하고, 해당 경험과 관련된 공개 가능한 근거를 연결했습니다.

### 5. Public Scope
개인 페이지에 어떤 정보를 공개할지 직접 기준을 정했습니다.

**공개하는 정보**
- 공부 중인 분야
- 실습 경험
- 문제 해결 과정
- 학습 방식

**공개하지 않는 정보**
- 전화번호 및 개인 이메일
- 상세 주소 및 위치 정보
- 개인 식별 정보
- 비밀번호 · 토큰 · API Key

## ✨ 구현 기능

- 1366×768 / 1920×1080 환경을 고려한 화면 구성
- 핵심 내용을 첫 화면에서 확인할 수 있도록 구성
- 마우스와 키보드로 실행 가능한 실습 근거 상세보기
- Tab 키를 이용한 키보드 접근
- 명확한 제목 구조와 텍스트 대비 고려
- `prefers-reduced-motion`을 이용한 움직임 최소화 설정
- 개인정보 및 비밀값을 포함하지 않는 공개 페이지 구성

## 🎯 제작 과정에서 중요하게 생각한 점

이번 과제에서는 예쁘게 보이는 페이지를 만드는 것뿐만 아니라, 다른 사람이 실제로 페이지를 확인할 수 있도록 만드는 것을 중요하게 생각했습니다.

화면 크기에 따라 핵심 내용이 잘리지 않는지 확인하고, 마우스뿐만 아니라 키보드로도 주요 기능을 사용할 수 있도록 구성했습니다. 또한 공개할 정보와 공개하지 않을 정보를 구분해 개인 페이지에 필요한 내용만 포함했습니다.

## 🤖 AI 활용

페이지의 HTML, CSS, JavaScript 작성과 레이아웃 및 접근성 조건을 점검하는 과정에서 AI를 활용했습니다.

페이지에 어떤 내용을 공개할지, 어떤 경험을 보여줄지, 최종 화면을 어떻게 구성할지는 직접 판단했습니다. 처음 제안된 화면 구성이 과제 조건과 맞지 않는 경우에는 그대로 사용하지 않고 수정 방향을 정해 다시 제작했습니다.
